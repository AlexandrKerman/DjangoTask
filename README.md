# SkyStore
Django-проект, содержащий 2 страницы:
- Домашняя (/)
- Контакты (contacts/)
## Установка и запуск
1. Создать виртуальное окружение
```bash
python -m venv .venv
```
2. Активировать окружение из папки .venv/scripts
```bash
.venv/scripts/activate
```
3. Установить зависимости
```bash
pip install -r requirements.txt
```
4. Запустить сервер
```bash
python manage.py runserver
```
